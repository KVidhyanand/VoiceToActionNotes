# VoiceToActionNotes (Flutter)
This application is to record the voice of the user and transcribe it into a structural text. And this information in the next stage should be fed to a LLM or a SLM, which is either a large language model or a small language model, which would convert it into actionable points so that these point could be stored under notes of the user

## Getting Started

This project is used to display the tokens of the projects w.r.t Doctors at the Hospital or Clinic to easily view and visit doctors.
